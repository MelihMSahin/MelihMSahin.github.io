# Prototype Evaluation Tasks

Run the same tasks on every prototype at **390 CSS px** and a representative desktop width such as **1440 CSS px**. Use the same milestone content and note any viewport-specific differences.

1. Find all seven Must-have milestones and report each title with its displayed date:
   - Moved to the UK
   - Kingston Academy
   - Queen Mary degree
   - Globant internship
   - Final-year project
   - Sprift unified API
   - Graduate Software Engineer at Deloitte
2. Identify the chapter assigned to each of the seven milestones.
3. Open a milestone preview using only the keyboard. Identify when focus enters the preview, then close it using the keyboard and confirm focus returns to the control that opened it.
4. Complete the milestone-finding, chapter-identification, preview-opening, and preview-closing tasks without map gestures. Do not rely on panning, pinch-zooming, dragging, or spatial position to find or activate content.
5. Navigate the prototype using only the keyboard and check that every interactive control has a visible focus indicator and a usable keyboard path.
6. Repeat relevant interaction checks with reduced motion enabled; confirm that no information or functionality depends on animation.

Record the viewport, input method, task outcome, and any point of confusion or accessibility barrier for each run.
