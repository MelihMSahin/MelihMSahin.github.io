# MelihMSahin.github.io

A personal software engineering portfolio for Mehmet Melih Sahin, designed to help engineering teams understand his work, interests, and direction across system design, ML/AI systems engineering, and reliability/platform engineering. Selected project stories and a layered timeline will offer more than a conventional CV.

The experience will be mobile-first and concise for recruiters, with clear paths to the CV and contact details and optional depth into projects, milestones, and personal context.
