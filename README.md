# MelihMSahin.github.io

A personal software engineering portfolio for Mehmet Melih Sahin, designed to help engineering teams understand his work, interests, and direction. It will balance software architecture and systems design with AI engineering, using selected project stories and a layered timeline to offer more than a conventional CV.

The experience will be mobile-first and concise for recruiters, with clear paths to the CV and contact details and optional depth into projects, milestones, and personal context.
